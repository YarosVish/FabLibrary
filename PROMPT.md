# Промт: как собрать такое же приложение самому с Claude

Скопируйте текст ниже в новый чат Claude. Нужен режим, где Claude может работать со встроенным браузером и файлами на компьютере (приложение Claude для ПК).

---

Я пользуюсь Fab.com, а раньше пользовался Unreal Marketplace и Quixel Megascans. Собери мне настольное приложение для Windows на Electron, офлайн-каталог моих ассетов. Требования:

1. Вход. Пароли я ввожу сам в окнах входа приложения: fab.com, accounts.epicgames.com, quixel.com. Приложение хранит только cookies сессии в отдельном разделе (partition) и работает запросами из страниц этих сайтов, как сам сайт. Никаких ключей из скриптов сайтов не извлекать.
2. Данные каждого аккаунта Epic хранятся в отдельной папке `%APPDATA%/<App>/profiles/<epicId>`, чтобы приложение можно было передать другому человеку.
3. Вкладка «Библиотека». Сначала синхронизация:
   - все мои паки с Fab: `/i/library/search?source=acquired`, детали из `/i/listings/<id>`; для снятых с продажи — `/i/library/assets/<entitlementId>`;
   - история заказов Epic (`/account/v2/payment/ajaxGetOrderHistory`), сумма трат по валютам и годам.

   Потом фильтры:
   - откуда (куплено / бесплатно / раздача);
   - тип;
   - стиль;
   - сеттинг;
   - формат;
   - MetaHuman (персонажи, волосы и грумы, одежда, кожа, анимации, инструменты);
   - «поддерживает UE 5.8» для плагинов.
4. Вкладка «Quixel»:
   - мои ассеты с quixel.com: `/v1/assets/acquired` и `/v1/assets/<id>` с заголовком Authorization из cookie `auth`, как делает сайт;
   - мои Megascans на Fab: продавец «Quixel Megascans» плюс `/i/users/me/listings-states`;
   - Quixel-ID для паков Fab — из имён файлов в `/i/listings/<id>/asset-formats`;
   - объединение по ID с отметкой «Fab и Quixel / Только Fab / Только Quixel»;
   - категории как в Bridge;
   - кнопка копирования ID;
   - превью подгружать лениво.
5. Вкладка «Вишлист»:
   - официальный вишлист (`/i/listings/search?in=wishlist`) плюс мои добавленные по ссылке без лимита;
   - цены из `/i/listings/prices-infos`, скидки, история цен;
   - приоритет, целевая цена, заметки;
   - купленное убирать автоматически.
6. Превью кэшировать локально (до 320 px), карточки и таблица, поиск, избранное, экспорт CSV, кнопка «Обновить» (всё или по частям), инкрементальная синхронизация.
7. Сборка: `Запуск.bat`, который при отсутствии Node.js скачивает портативный Node с nodejs.org (с проверкой SHA256), ставит Electron и запускает приложение. Положи всё в папку на моём диске и проверь интерфейс на тестовых данных.

---

Готовую версию можно просто попросить у автора: это та же папка, её достаточно запустить через `Запуск.bat` и войти в свой аккаунт.
